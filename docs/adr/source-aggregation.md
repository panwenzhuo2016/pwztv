# 应用内来源聚合与订阅更新

选择应用内聚合，不新增服务端。订阅清单只负责提供候选频道和影片，播放失败由现有播放器反馈；来源目录、缓存更新与恢复规则共享给手机和电视界面。复用现有 M3U/TXT 解析器、采集接口和播放器，不新增视频代理。

来源属于外部依赖，清单成功下载不能证明媒体可播。随包提供快照，后台有限下载，校验通过才原子替换私有缓存；网页、错误 JSON 和超限响应不覆盖可用缓存。每份来源的在途请求合并，3 个下载线程，首次无快照订阅总等待不超过 12 秒。

频道按稳定标识聚合，保留地区版本；无标识国际频道仅在相同来源分组内合并。播放线路携带自己的请求头和 DRM 参数，避免合并后使用其他来源的认证信息。公网默认过滤 RTP 组播和明显内网地址。

恢复有明确边界：直播记录本轮已失败线路，即使冷却到期也不会重复尝试；点播按站点和影片 ID 记录访问，跨站搜索每轮一次，候选数上限可配置。换站校验片名、年份和集数，保留内存进度。播放恢复后清空本轮状态，用户主动选择新片重新开始。

代价是本机网络决定可访问范围，公开接口可能有地域、时效和访问频率限制，无法承诺全网覆盖。扩大覆盖采用追加订阅和更新快照，不把不可验证的可播承诺写入界面。
